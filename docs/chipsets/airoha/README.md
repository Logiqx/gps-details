## Airoha

### Overview

Airoha (a subsidiary of MediaTek) typically do not make press releases for their new GNSS chipsets.

The chips often come to light through hardware teardowns, regulatory filings, and semiconductor analysis reports.

Numerous watches use an Airoha GNSS chipset and these can be found on a separate [page](devices.md).

The latest Airoha GNSS chipsets can be found on their [website](https://www.airoha.com/products-list/tech/xeHM5uGAi56z8OSz).

#### AG3365

The AG3365 supports L1 + L5 but only at 2 Hz, unlike previous chipsets which supported 10 Hz.

First observed in the [COROS](../../devices/coros/chipsets/README.md) NOMAD which was announced in Aug 2025.



#### AG3352

The AG3352 supports L1 only and is a newer chip than the AG3335MN.

First referenced in announcement for [Quectel LC76G](https://www.gpsworld.com/quectel-launches-high-performance-gnss-positioning-module/) in Jun 2022.

First observed in the Garmin [vívoactive 6](../../devices/garmin/watches/vivoactive.md) which was released in Apr 2025.



#### AG3335MN

The AG3335MN appears in some single-band watches, presumably cheaper than the AG3335M.

The AG3335MN was referenced in a floorplan analysis by [TechInsights](https://www.techinsights.com/products/bfr-2106-804) in Sep 2021.

First observed in the Garmin [fēnix 7](../../devices/garmin/watches/fenix.md) which was announced in Jan 2022.

There is a nice blog article talking about the AG3335 family by [Kalmix](https://www.kalmixtech.com/blogs/blog/ag3335-variants-explained-m-a-at-ad).




#### AG3335M

The AG3335M supports L1 + L5 and appeared in a lot of different watches supporting multi-band GNSS.

First observed in the [COROS](../../devices/coros/chipsets/README.md) VERTIX 2 which was announced in Aug 2021.

There is a nice blog article talking about the AG3335 family by [Kalmix](https://www.kalmixtech.com/blogs/blog/ag3335-variants-explained-m-a-at-ad).
