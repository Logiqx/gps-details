## Garmin Product Numbers

Garmin product details can be obtained via the Garmin API but they need tidying up.

I have created a repository on [Github](https://github.com/Logiqx/garmin-ids) which contains a sanitised list of Garmin products.

The Github repository is at [https://github.com/Logiqx/garmin-ids](https://github.com/Logiqx/garmin-ids).
